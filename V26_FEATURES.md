# ZenithMax V26.0 — Discovery & Personalization

V26 adds a user-controlled discovery layer while preserving V25 release-candidate systems.

## Added
- For You / Following / Trending / Latest home-feed modes
- Interest preferences (up to 12 topics)
- Preference-aware recommendation scoring
- Continue Watching from saved playback progress
- Not Interested content controls
- Autoplay preference
- Data saver preference
- Dedicated For You personalization page
- Hidden-video records stored server-side
- V26 API metadata and schema migration

## Production truth
Personalization is implemented in the ZenithMax application. External storage, database, email, payment, TURN and video-processing providers remain adapter-ready until real provider credentials are configured.
